How to Record a Transaction
Daily Sales
The Health Collective Inc.
Every patient visit is recorded as a Transaction. A transaction has three parts: the customer (who came in), the services (what was done), and the tenders (how payment was made). The total tenders must equal the total services minus all discounts before a transaction can be submitted.
Recording a Transaction
1
Open a new transaction
  • Go to Operations → Daily Sales — the service type cards appear only when viewing today
  • Click the card for the patient's visit type (e.g., OPD, APE) to open a pre-typed new transaction form
2
Fill in the header fields
  • Record Date — defaults to today; change only if recording a past visit
  • Record Number — auto-generated; do not edit
  • Transaction Type — select the service category (OPD, APE, etc.)
  • DashLabs Number — internal lab reference number, if applicable
  • POS / Storehub Number — POS receipt number, if applicable
3
Enter the customer
  • Type the patient's name in the Customer field — it will autocomplete from existing records
  • If the patient is new, keep typing the name until the dropdown shows + Add Customer, click it to open the registration form, fill in the name and sex, then save — the name is inserted automatically
4
Add services
  • In the Services section, type the service name — it will autocomplete
  • Enter the Amount for each service
  • Add a Discount on a line if applicable (must not exceed the line amount)
  • Click + Add service for each additional service
  • A Less: Discount field in the totals summary applies an overall discount on top of any line discounts
5
Add tenders (payment)
  • In the Tenders section, select how the patient paid (Cash, GCash, Credit, HMO, etc.)
  • Enter the amount for each tender
  • Click + Add tender if the patient paid using more than one method
Balance rule: Total tenders must exactly equal total services minus all discounts. The form will not let you submit until they match.
6
Save or Submit
Save & Submit
  • Finalizes the transaction
  • Appears in daily totals and reports
  • Cannot be edited after submitting
  • Use this when the visit is complete and payment is confirmed
Save Draft
  • Saves the transaction without finalizing
  • Does not appear in totals or reports
  • Can still be edited or deleted
  • Use when information is incomplete or pending
Editing & Cancelling
!
Draft transactions

Drafts can be edited freely. Open the transaction from the daily list and make changes, then save or submit.

!
Submitted transactions

Submitted transactions are locked and cannot be edited. If a correction is needed, open the transaction and use the Cancel button, then record a new transaction with the correct information.

Note: Only users with admin rights can cancel a submitted transaction.
APE Transactions

APE (Annual Physical Examination) transactions require an additional step before recording individual employees — a Batch must first be created for the company. When the Transaction Type is set to APE, a batch selector appears and automatically fills the Credit tender with the package amount. See the How to Record APE guide for the full workflow.
