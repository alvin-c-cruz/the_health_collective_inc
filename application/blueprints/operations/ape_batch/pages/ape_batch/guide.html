How to Record APE
Annual Physical Examination
The Health Collective Inc.
APE transactions are recorded in two stages. First, open a Batch for the company — one batch covers the entire engagement and holds the LOA/SOA reference and per-employee package price. Then record a Transaction for each employee, linked to that batch.
Before You Start
✓
Add the Company (first time only)
  • Go to Options → Company
  • Click Add Company, enter the company name, contact person, and contact number
  • Save — the company will now appear in the APE Batch form
✓
Verify the APE service type exists
  • Go to Operations → Service Types
  • Confirm there is a service type with code APE
  • If not, add one with that exact code — the transaction form uses it to show the batch selector
Step 1 — Create an APE Batch
1
Open a new batch
  • Go to Operations → APE Batch and click New Batch
2
Fill in the batch details
  • Company — select the corporate client
  • Batch Date — date of the engagement (defaults to today)
  • LOA / SOA # — reference number from the company's letter of authorization or statement of account
  • Package Amount — standard per-employee price billed to the company (e.g., 1,500.00); this auto-fills the Credit tender when recording each employee
  • Notes — optional remarks
3
Save
  • You'll land on the batch detail page showing 0 employees and 0 total sales
  • Return here to monitor progress as employees come in
Step 2 — Record Each Employee Transaction
1
Start a new transaction
  • Go to Operations → Daily Sales → New Transaction
2
Set Transaction Type to APE
  • Select APE in the Transaction Type field
  • The APE Batch selector will appear below it
3
Select the APE Batch
  • Choose the batch created in Step 1
  • The Credit tender is automatically filled with the package amount
4
Enter the patient and services
  • Patient — enter the employee's name
  • Services — add the specific tests performed (CBC, X-ray, Urinalysis, etc.) with their individual amounts
5
Review the tender section
  • The Credit tender (pre-filled) covers the package amount — the company's share
  • If the employee is paying for add-on tests out of pocket, add a Cash tender row for the extra amount
  • Total tendered must equal total services charged
Example: Package is ₱1,500. Employee also paid ₱300 for an add-on test. Services total ₱1,800. Tenders: Credit ₱1,500 + Cash ₱300 = ₱1,800.
6
Save and Submit
  • Click Save & Submit to finalize, or Save to keep as draft
Monitoring & Collections
  • Go to Operations → APE Batch → View to see all linked employee transactions, total employee count, and total sales for the batch.
  • The Credit tender on each APE transaction is a receivable from the company. It appears in Collections under the Credit tender group and can be settled when the company pays the SOA.
  • Cash amounts paid by employees are collected upfront and require no follow-up.
